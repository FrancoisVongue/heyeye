# EYE — порядок работ

Стратегия: вертикальный срез. Сначала тонкая сквозная нитка glance → мозг → focus,
потому что самая рискованная гипотеза — «модель умеет ориентироваться по эскизу».
Инфраструктура (MCP, watch) — только после её подтверждения.

- [x] **Этап 6 — watch()** — что изменилось после действия
      *DAMAGE (X сам говорит, где перерисовали) + сравнение с копией экрана по клеткам 8×8 → точные места
       реальных изменений; ожидание «экран успокоился» вместо фиксированных пауз; /act отвечает, что изменилось
       и какие узлы задело; /changes — что изменилось с последнего взгляда. Мигающая каретка не считается.*
- [x] **Память прочитанного текста** — чтение было ~85–90% времени разбора
      *отпечаток пикселей самого текста (без полей рамки) → модель читает только незнакомые куски, каждый на
       чистом фоне своего цвета. Память совпадает с чтением с нуля пиксель в пиксель (проверено: 0 расхождений).
       Повторный разбор после прокрутки/ввода в 2.5–3 раза быстрее (на 2-ядерной машине 2.4 с → 0.8–0.95 с).*
