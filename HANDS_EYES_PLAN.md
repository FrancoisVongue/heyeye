## Инструменты (research 2026 — берём готовое, не пишем костыли)

### Руки на уровне ОС — **nut.js** (Python НЕ нужен ✅)
- [nut.js](https://nutjs.dev/) — Node, нативные N-API аддоны, mouse+keyboard+screen+clipboard, macOS/Win/Linux. Современный, живой.
- [RobotJS](https://robotjs.dev/) — старый, тянет Python, развитие заглохло → **не берём**.
- [AutoAnchorJS](https://github.com/Anchorclick/autoanchorjs) — на Rust-бинарях, запасной вариант.
- **Вывод:** ты был прав — без Python. `nut.js` даёт move/click/dblclick/drag/scroll/type/hotkey по абсолютным координатам экрана. Мой `/act` уже в этих терминах — меняется только «как послать событие».

### Глаза — скриншот + разметка НА ЧИСТОМ JS (Python ВЫКИНУТ ✅)
- Скриншот: macOS `screencapture` (встроено) / в браузере CDP screenshot.
- **Разметка без Python:** модели OmniParser (YOLO-детектор иконок + OCR) — стандартные, их
  **экспортируют в ONNX и гоняют в JS** через [onnxruntime-node](https://onnxruntime.ai/docs/) /
  [transformers.js](https://huggingface.co/docs/transformers.js/en/index) + OCR через tesseract.js.
  **Питона в рантайме НОЛЬ.** Повторяем пайплайн OmniParser на JS.
- **Но даже это — оптимизация, а не условие.** Для способности глаза = сам скриншот: модель
  смотрит на png и решает координаты. Детектор нужен лишь чтобы сделать «взгляд» дешёвым (фовеа).
- **DOM/HTML УБРАН из перцепции** (в `eye/_archive_dom/`). Никакого чтения кода — только пиксели.

## Что нужно от тебя (разово, когда вернёшься) — разрешения macOS
Управление реальными мышью/клавиатурой и захват всего экрана macOS гейткипит:
1. **Системные настройки → Приватность → Универсальный доступ (Accessibility)** → добавить Terminal/node.
2. **Приватность → Запись экрана (Screen Recording)** → добавить Terminal/node.
Это разовый тумблер (не «Allow» на каждый раз). До этого ОС-версию не протестировать — поэтому
сегодня я тренировался в браузере (там разрешений не надо).
